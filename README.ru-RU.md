## О плагине

ComfyUI-Global-Translation — плагин многоязычного перевода интерфейса. Он следует языковой настройке ComfyUI (Настройки → Общие → `Comfy.Locale`) и дополняет перевод узлов, меню, панели настроек, менеджера и интерфейсов сторонних узлов. Плагин также переводит текст интерфейса, который сторонние узлы обновляют динамически. Охват перевода зависит от словаря каждого языка.

### Почему этот плагин?

| Возможность | Этот плагин | Другие плагины перевода |
|------|--------|-------------|
| Совместимость с офиц. переводом | ✅ Дополняет перевод интерфейса на выбранном в ComfyUI языке | ❌ Возможны конфликты |
| Функции контекстного меню | ✅ Работают после перевода | ❌ Часть функций ломается |
| Совместимость со старым и новым UI | ✅ Двойная кнопочная архитектура | ❌ Только одна версия |
| Переключатель перевода | ✅ При переключении страница перезагружается | — |
| Защита пользовательских заголовков | ✅ Не перекрывает правки пользователя | ❌ Могут быть перезаписаны |

## Основные возможности

### 🎯 Умная система перевода

- **Умное обнаружение** — автоматически распознаёт уже переведённый текст, избегая повторного перевода и бесконечной рекурсии
- **Совместимость с нативным переводом** — идеально сосуществует с официальным переводом ComfyUI без взаимных помех
- **Учёт контекста** — применяет оптимальную стратегию в зависимости от типа элемента (узлы, меню, виджеты и т. д.)
- **Объединение переводов** — Переводы одного узла объединяются по полям. Если удалось определить плагин узла, его словарь имеет приоритет.
- **Перевод пользовательских панелей** — Поддерживаются кнопки, подписи элементов управления, текст-заполнитель и всплывающие окна в панелях узлов.
- **Перевод контекстных меню** — Меню показывает перевод подписей. Отключение связей, переименование и другие действия используют исходные пункты и значения.

### 🎨 Красивый интерфейс

- **Сегментированная кнопка-пилюля** — круглая кнопка-переключатель с синим ползунком, плавно скользящим между сегментами «вкл/выкл», современный вид
- **Радужная анимация** — в активном состоянии отображается плавная радужная градиентная анимация
- **Минималистичный серый дизайн** — в неактивном состоянии используется элегантный серый градиент
- **Незаметный нативный режим** — по желанию сдержанная расцветка в стиле темы ComfyUI
- **Обратная связь в реальном времени** — текст и цвет кнопки мгновенно отражают текущее состояние перевода

### 🔧 Гибкое управление переводом

- **Мгновенное переключение** — включать/отключать перевод без перезапуска
- **Сохранение состояния** — настройки сохраняются автоматически и переживают перезапуск
- **Интеграция в панель настроек** — в настройках ComfyUI можно задать стиль переключателя и перевод выпадающих опций (язык следует официальному параметру ComfyUI)
- **Переводы отдельных плагинов** — Перевод узлов можно включать и выключать для каждого файла перевода.
- **Обновление словарей** — После добавления или изменения файлов перевода обновите страницу.

### 🛡️ Стабильность и надёжность

- **Полная обработка исключений** — все ключевые операции обёрнуты
- **Устойчивость к ошибкам словарей** — Нечитаемые или неверно структурированные словари пропускаются. Их имена записываются в журнал.
- **Сохранение пользовательских данных** — Редактируемый текст, промпты и заданные пользователем имена файлов и папок на панели рабочих процессов сохраняются.
- **Поддержка нескольких версий** — совместим со старым и новым интерфейсом ComfyUI

## Установка

### Способ 1: клонирование через Git (рекомендуется)

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/a63976659/ComfyUI-Global-Translation.git
```

После установки перезапустите ComfyUI.

#### Способ 1 — подробная инструкция для новичков:

1. Откройте папку плагинов `ComfyUI\custom_nodes`
2. На Win11 щёлкните правой кнопкой на пустом месте и выберите «Открыть в терминале». На Win10 введите `cmd` в адресной строке и нажмите Enter.
3. Нажмите **Code** в правом верхнем углу этой страницы и скопируйте адрес (можно скопировать и URL).
4. В терминале введите `git clone `, вставьте адрес и нажмите Enter. Пример: `git clone https://github.com/a63976659/ComfyUI-Global-Translation.git`
5. Готово — перезапустите ComfyUI. (Если установка не удалась, включите прокси/VPN и повторите.)



### Способ 2: ComfyUI Manager

1. Откройте ComfyUI Manager
2. Переключите источник данных на: Канал (удалённый)
3. Нажмите «Менеджер узлов»
4. Выполните поиск **猪的飞行梦**
5. Нажмите «Установить» и перезапустите ComfyUI

### Способ 3: ручное скачивание (не рекомендуется, без обновлений)

1. На странице GitHub нажмите **Code → Download ZIP**
2. Распакуйте в `ComfyUI/custom_nodes/ComfyUI-Global-Translation`
3. Перезапустите ComfyUI

## Использование

### Переключатель перевода

Нажмите переключатель перевода на панели инструментов. С клавиатуры выберите его клавишей Tab и нажмите Enter или пробел. После успешного сохранения страница автоматически обновится.

- **Перевод включён** — Переключатель показывает «Перевод вкл», а интерфейс переводится на текущий язык ComfyUI.
- **Перевод выключен** — Переключатель показывает «Перевод выкл», а ComfyUI и сторонние узлы возвращают исходный текст интерфейса.

### Язык перевода

Язык перевода больше не задаётся внутри плагина — он **автоматически следует официальному языковому параметру ComfyUI** (Настройки → Общие → Язык / `Comfy.Locale`):

- Плагин поддерживает все 14 языков, официально доступных в ComfyUI: упрощённый и традиционный китайский, английский, японский, корейский, русский, французский, испанский, итальянский, португальский (Бразилия), турецкий, арабский, персидский, иврит; непокрытые языки откатываются к английскому
- В плагин включён словарь немецкого языка (`de-DE`). В официальных языковых настройках ComfyUI немецкий пока недоступен.
- После смены официального языка в настройках ComfyUI страница автоматически обновляется, перевод и строки интерфейса плагина вступают одновременно, ручной перезапуск не нужен

### Панель настроек

В ComfyUI Настройки → «🌐 Настройки перевода» доступны два параметра. Строки интерфейса локализованы на текущий язык, порядок разделов едилен для всех языков:

| Параметр | Описание | Варианты |
|-------|------|------|
| 🎨 Стиль переключателя | Выбор внешнего вида; перерисовка мгновенно, без обновления | pill (сегментированная пилюля) / gradient (радужный) / plain (нативный незаметный) |
| 📋 Выпадающие опции | Переводить ли также текст опций в раскрывающихся списках COMBO | Вкл / Выкл (автообновление при изменении) |

**Управление переводом плагинов** под настройками показывает доступные файлы перевода узлов. Снимите флажок, чтобы отключить переводы выбранного файла. Если список загрузился и в нём есть элементы, нажмите «Сохранить и перезагрузить». Отключения для других языков сохраняются. При ошибке панель покажет сообщение и позволит повторить сохранение.

### Справочник стилей кнопок

| Стиль | Включено | Выключено | Для чего подходит |
|-----|---------|---------|----------|
| **Сегментированная пилюля** | Синий ползунок поверх сегмента «вкл», жирный белый текст | Синий ползунок переехал на «выкл», серый текст | Современный минимализм, состояние с одного взгляда |
| **Радужный градиент** | Переливающаяся радуга, жирный белый | Переливающийся серый, жирный тёмный | Хотите наглядно и заметно |
| **Нативный незаметный** | Фон в цвет темы ComfyUI | Тёмный фон, серый текст | Хотите слиться с интерфейсом |

> Нажатие в любой точке сегментированного переключателя меняет его состояние. После успешного сохранения ползунок перемещается, и страница обновляется. При ошибке сохраняется прежнее состояние и можно нажать переключатель ещё раз.

### Добавление собственного перевода

Создайте JSON-файл в каталоге `ru-RU/Nodes/`:

```json
{
  "YourNodeClassName": {
    "title": "Отображаемое имя узла",
    "inputs": {
      "input_name": "перевод имени входа"
    },
    "outputs": {
      "output_name": "перевод имени выхода"
    },
    "widgets": {
      "widget_name": "перевод имени виджета"
    },
    "ui": {
      "English text in panel": "перевод текста в панели"
    }
  }
}
```

> **Советы по написанию**
>
> - Ключи `widgets` должны использовать **настоящее имя** виджета (имя параметра в исходном коде, например `target_language`), а не отображаемый display_name (например `Target Language`). Для плагинов V3 API (io.Schema) рекомендуется писать оба ключа — настоящее имя и display_name — для наилучшей совместимости
> - Поле `ui` переводит английский текст внутри самодельных панелей узла (созданных через `addDOMWidget`): ключ — отображаемый английский оригинал, значение — перевод
> - Не добавляйте «тождественные переводы» (значение равно ключу, например `"cfg": "cfg"`) — они не несут переводческого смысла
> - Проверяйте орфографию ключей; несовпадение с исходным кодом (например лишняя `t` в `perturb_atttn`) приведёт к тому, что виджет не переведётся

Создайте JSON-файл в каталоге `ru-RU/Menus/`, чтобы добавить переводы меню:

```json
{
  "English Menu Text": "перевод текста меню",
  "Another Item": "другой пункт"
}
```

Верхний уровень файла словаря должен быть объектом JSON. Если подходящего перевода нет, отображается исходный текст. Ошибочные файлы пропускаются и регистрируются в журнале. Словари сортируются по имени файла. При совпадении ключей используется перевод из файла, расположенного дальше по порядку. Если удалось определить плагин узла, его словарь имеет приоритет, а остальные записи дополняют недостающие поля.

> После добавления, изменения или удаления словаря обновите страницу браузера. После обновления плагина сначала перезапустите ComfyUI, затем обновите страницу.

### Перевод блюпринтов и подграфов

Перетащите блюпринт из раздела «Узлы» → «Comfy Blueprints» на холст или откройте официальный шаблон либо собственный рабочий процесс с подграфами. Классический холст и новый интерфейс узлов переводят открытые порты, подписи виджетов и текст-заполнитель на текущий язык. Это относится и к элементам из вложенных подграфов.

- Названия официальных блюпринтов и распознанных подграфов официальных шаблонов ищутся в `Menus/` текущего языка. Пользовательские названия собственных подграфов сохраняются. Названия и общие термины для упрощённого китайского собраны в [ComfyUI-子图.json](zh-CN/Menus/ComfyUI-子图.json).
- Приоритет имеет перевод соответствующего поля внутреннего узла. Если его нет, `Menus/` проверяется по полному отображаемому имени. Допускаются различия в регистре, пробелах, знаках подчёркивания и дефисах. Одна запись может использоваться несколькими подграфами.
- Для разных переводов входа и выхода используйте префиксы `input.` и `output.`. Например, `output.depth_colored` относится к одноимённому выходу. В рабочем процессе сохраняются исходные названия, имена портов и значения параметров.

### Ключевые технологии

| Технология | Описание |
|------|------|
| **Встроенные контекстные меню** | Переводит подписи после построения меню в ComfyUI. Пункты, обработчики и значения списков используют исходные данные. |
| **Двойная кнопочная архитектура** | Поддерживает и старый `.comfy-menu`, и новый `.comfyui-menu` |
| **MutationObserver** | Отслеживает изменения интерфейса. Изменения меню из одной группы проверяются за один проход. |
| **translatedValueSet** | Использует Set для O(1)-проверки, переведён ли текст, избегая повторной обработки |
| **Защита листовых узлов** | Присваивает `innerText` только узлам без детей, защищая привязку событий Vue |
| **Кэш переводов** | Подготавливает и сжимает переводы в фоне. Повторно использует результат при тех же словарях и отключениях. |
| **Кэш сопоставлений подграфа** | Повторно использует сопоставления подграфа и обновляет их при изменении имени графа или идентификаторов открытых портов. |
| **Передача Gzip** | Отправляет сжатые данные, если браузер принимает Gzip. |

## Примечания

### Совместимость

- **Конфликт плагинов перевода** — этот плагин конфликтует с другими плагинами перевода (например AIGODLIKE-ComfyUI-Translation); удалите их перед использованием
- **Известный конфликтующий плагин** — у `ComfyUI Browser` возможны проблемы совместимости
- **Поддержка браузеров** — рекомендуются Chrome, Edge, 360 Browser; другие браузеры недостаточно протестированы

### Если перевод ещё не обновился

- **После обновления страницы отображается старый перевод.** Некоторые средства синхронизации заменяют словарь, сохраняя размер, время изменения и запись каталога. Плагин может продолжать использовать кэш. Перезапустите ComfyUI, чтобы прочитать словарь заново.
- **Обновлённый текст всплывающего окна остался на английском.** Некоторые окна меняют текст состояния сразу после открытия. Новый текст может временно оставаться на английском.
- **После изменения связи открытый порт показывает старый перевод.** Новая связь внутри подграфа действует сразу. Сохраните и заново откройте рабочий процесс, чтобы обновить сопоставление перевода порта.
