## 플러그인 소개

ComfyUI-Global-Translation은 다국어 인터페이스 번역 플러그인입니다. ComfyUI의 언어 설정(설정 → 일반 → `Comfy.Locale`)에 따라 노드, 메뉴, 설정 패널, 매니저 및 타사 노드의 인터페이스에 번역을 추가합니다. 타사 노드가 동적으로 갱신하는 화면 텍스트도 번역합니다. 플러그인 자체의 인터페이스는 15개 언어를 지원하며 번역 범위는 언어별 사전에 따라 달라집니다.

### 이 플러그인을 선택해야 하는 이유?

| 특성 | 본 플러그인 | 기타 번역 플러그인 |
|------|--------|-------------|
| 공식 번역 호환 | ✅ ComfyUI에서 선택한 언어의 화면 번역을 추가 | ❌ 충돌 가능 |
| 우클릭 메뉴 기능 | ✅ 번역 후 기능 정상 동작 | ❌ 일부 기능 상실 |
| 구/신 버전 UI 호환 | ✅ 이중 버튼 구조 | ❌ 단일 버전만 지원 |
| 번역 전환 | ✅ 전환하면 페이지가 새로고침됨 | — |
| 사용자 지정 제목 보호 | ✅ 사용자 수정을 덮어쓰지 않음 | ❌ 덮어써질 수 있음 |

## 핵심 기능

### 🎯 지능형 번역 시스템

- **지능형 감지** — 이미 번역된 텍스트를 자동 인식하여 중복 번역과 무한 재귀를 방지
- **기본 번역 호환** — ComfyUI 공식 번역과 완벽히 공존하며 서로 간섭하지 않음
- **문맥 인식** — 인터페이스 요소 유형(노드, 메뉴, 위젯 등)에 따라 가장 적합한 번역 전략 적용
- **번역 데이터 병합** — 같은 노드의 번역을 필드별로 합칩니다. 노드가 속한 플러그인을 식별할 수 있으면 해당 사전을 우선 사용합니다.
- **사용자 정의 패널 번역** — 노드의 사용자 정의 패널에 있는 버튼, 컨트롤 레이블, 자리 표시자, 팝업을 번역합니다.
- **우클릭 메뉴 번역** — 메뉴 레이블을 번역합니다. 연결 끊기와 이름 변경 등의 동작은 원래 메뉴 항목과 값을 사용합니다.

### 🎨 아름다운 사용자 인터페이스

- **캡슐 세그먼트 컨트롤** — 둥근 캡슐 형태의 슬라이딩 토글. 파란 슬라이더가 '켜기/끄기' 구간을 매끄럽게 전환되어 세련된 인상
- **무지개 동적 효과** — 활성 상태에서 부드러운 무지개 그라데이션 애니메이션 표시
- **회색 심플 디자인** — 비활성 상태에서 우아한 회색 그라데이션 적용
- **네이티브 저조용 모드** — ComfyUI 기본 테마와 일치하는 절제된 배색 선택 가능
- **실시간 상태 피드백** — 버튼 텍스트와 색상이 현재 번역 상태를 실시간 반영

### 🔧 유연한 번역 관리

- **실시간 전환** — 재시작 없이 번역 켜기/끄기
- **상태 영속화** — 설정이 자동 저장되어 재시작 후에도 유지
- **설정 패널 통합** — ComfyUI 설정 패널에서 토글 스타일과 드롭다운 옵션 번역 구성(번역 언어는 ComfyUI 공식 언어 설정을 자동 추적)
- **플러그인별 번역 전환** — 노드 번역 파일별로 번역을 켜거나 끌 수 있습니다.
- **사전 다시 불러오기** — 번역 파일을 추가하거나 수정한 후 페이지를 새로고침합니다.

### 🛡️ 안정적이고 신뢰할 수 있음

- **완비된 예외 처리** — 모든 핵심 작업에 오류 처리 포함
- **사전 오류 처리** — 읽을 수 없거나 형식이 잘못된 사전은 건너뛰고 파일 이름을 로그에 기록합니다.
- **사용자 콘텐츠 보호** — 편집 가능한 텍스트, 프롬프트, 워크플로 사이드바에서 사용자가 지정한 파일과 폴더 이름을 유지합니다.
- **다중 버전 호환** — ComfyUI 구/신 버전 인터페이스 동시 지원

## 설치 방법

### 방법 1: Git 클론 (권장)

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/a63976659/ComfyUI-Global-Translation.git
```

설치 완료 후 ComfyUI를 재시작하세요.

#### 방법 1 — 초보자 상세 안내:

1. 플러그인 폴더 ComfyUI\custom_nodes 열기
2. Win11은 빈 공간에서 우클릭 후 '터미널에서 열기' 선택. Win10은 주소창에 cmd 입력 후 엔터.
3. 이 페이지 우측 상단의 Code를 펼쳐 주소 복사(URL을 그대로 복사해도 됨)
4. 명령창에 `git clone ` 입력 후 주소 붙여넣기하고 엔터. 예: `git clone https://github.com/a63976659/ComfyUI-Global-Translation.git`
5. 설치 완료, ComfyUI 재시작. (설치 실패 시 프록시를 켜고 재시도)



### 방법 2: ComfyUI Manager

1. ComfyUI Manager 열기
2. 데이터를 '채널(원격)'으로 변경
3. 노드 관리 클릭
4. **猪的飞行梦** 검색
5. 설치 클릭 후 ComfyUI 재시작

### 방법 3: 수동 다운로드 (비추천, 업데이트 불가)

1. GitHub 페이지에서 **Code → Download ZIP** 클릭
2. `ComfyUI/custom_nodes/ComfyUI-Global-Translation`에 압축 해제
3. ComfyUI 재시작

## 사용 방법

### 번역 토글

도구 모음의 번역 스위치를 클릭합니다. 키보드에서는 Tab 키로 스위치를 선택하고 Enter 키 또는 스페이스바로 전환합니다. 저장에 성공하면 페이지가 자동으로 새로고침됩니다.

- **번역 켜기** — 스위치에 ‘번역 켜짐’이 표시되고 화면을 ComfyUI에서 선택한 언어로 번역합니다.
- **번역 끄기** — 스위치에 ‘번역 꺼짐’이 표시되고 ComfyUI와 서드파티 노드의 원래 화면 텍스트로 돌아갑니다.

### 번역 언어

번역 언어는 더 이상 플러그인에서 개별 설정하지 않으며, **ComfyUI 공식 언어 설정**(설정 → 일반 → 언어 / `Comfy.Locale`)을 자동으로 따릅니다:

- 공식 지원 언어 모두 매칭: 간체 중국어, 번체 중국어, 영어, 일본어, 한국어, 러시아어, 프랑스어, 독일어, 스페인어, 이탈리아어, 포르투갈어(브라질), 터키어, 아랍어, 페르시아어, 히브리어. 미지원 언어는 영어로 폴백
- ComfyUI 설정에서 공식 언어를 전환하면 페이지가 자동 새로고침되며 번역과 플러그인 UI 문구가 동시에 반영됩니다. 수동 재시작 불필요

### 설정 패널

ComfyUI 설정 → '🌐 번역 설정'에 두 개의 구성 항목이 있습니다. UI 문구는 현재 언어로 현지화되며(15개 언어) 모든 언어에서 섹션 배열 순서가 일치합니다:

| 항목 | 설명 | 선택지 |
|-------|------|------|
| 🎨 토글 스타일 | 토글 외관 선택, 전환 후 즉시 새로고침 없이 재렌더 | pill (캡슐 세그먼트) / gradient (무지개 그라데이션) / plain (네이티브 저조용) |
| 📋 드롭다운 옵션 | COMBO 드롭다운 내 선택지 텍스트도 번역할지 여부 | 켜기 / 끄기 (수정 후 자동 새로고침) |

설정 아래의 **플러그인 번역 관리**에서 사용 가능한 노드 번역 파일을 확인할 수 있습니다. 체크를 해제하면 해당 파일의 노드 번역이 비활성화됩니다. 목록을 불러왔고 항목이 있으면 ‘저장 후 새로고침’을 선택할 수 있습니다. 다른 언어의 비활성화 설정은 유지됩니다. 저장에 실패하면 안내가 표시되며 다시 시도할 수 있습니다.

### 버튼 스타일 설명

| 스타일 | 켬 효과 | 끔 효과 | 사용 장면 |
|-----|---------|---------|----------|
| **캡슐 세그먼트** | 파란 슬라이더가 '켜기' 구간을 덮고 흰색 굵은 글씨 | 파란 슬라이더가 '끄기'로 미끄러지고 회색 글씨 | 모던 심플, 상태가 한눈에 |
| **무지개 그라데이션** | 무지개 흐름 애니메이션, 흰색 굵은 글씨 | 회색 흐름 애니메이션, 짙은 굵은 글씨 | 직관적으로 눈에 띄길 원할 때 |
| **네이티브 저조용** | ComfyUI 테마색 배경 | 짙은 배경, 회색 글씨 | 인터페이스에 녹아들길 원할 때 |

> 캡슐 스위치의 어느 위치를 클릭해도 전환할 수 있습니다. 저장에 성공하면 슬라이더가 이동한 뒤 페이지가 새로고침됩니다. 저장에 실패하면 기존 상태가 유지되며 다시 클릭할 수 있습니다.

## 번역 커버 범위

### 번역 내용

| 카테고리 | 커버 내용 | 상태 |
|------|---------|------|
| **노드 이름** | 모든 워크플로 노드의 제목과 표시 이름 | ✅ |
| **노드 속성** | 입/출력 포트, 위젯 레이블, 설명 | ✅ |
| **청사진과 하위 그래프** | 사전에 등록된 공식 청사진 및 템플릿 하위 그래프의 제목, 공식 및 사용자 정의 하위 그래프의 노출 포트, 위젯 레이블, 텍스트 입력란 자리 표시자 | ✅ |
| **메뉴 시스템** | 메인 메뉴, 우클릭 메뉴, 컨텍스트 메뉴 | ✅ |
| **설정 패널** | ComfyUI 설정 대화상자 | ✅ |
| **매니저** | ComfyUI Manager 인터페이스 | ✅ |
| **템플릿 라이브러리** | 워크플로 템플릿 이름 | ✅ |
| **인터페이스 요소** | 버튼, 레이블, 툴팁, 검색 상자 | ✅ |
| **사용자 정의 패널** | 노드 자체 DOM 패널의 버튼, 레이블, 드롭다운, 툴팁, 팝업 | ✅ |
| **큐 정보** | 큐 크기 등 동적 텍스트 | ✅ |

### 번역 파일 구조

```
ko-KR/
├── Nodes/          # 노드 번역(제목, 입력, 출력, 위젯, 사용자 정의 패널)
│   └── internal.json
├── Categories/     # 노드 분류 번역
│   ├── Internal.json
│   └── Other.json
└── Menus/          # 메뉴 및 인터페이스 번역
    ├── Comfy设置菜单及管理器菜单.json
    ├── Comfy条件选项.json
    ├── ComfyUI-子图.json
    ├── Comfy模版汉化-zdfxm.json
    └── ...
```

> 다른 언어 디렉터리(`zh-CN/`, `zh-TW/`, `en-US/`, `ru-RU/`, `fr-FR/`, `de-DE/`, `es-ES/`, `it-IT/`, `pt-BR/`, `ar-SA/`, `tr-TR/`, `fa-IR/`, `he-IL/`)도 동일한 구조이며 현재 언어에 따라 자동 로드됩니다. 그중 `en-US/`는 다른 언어 플러그인의 노드를 영어로 복원하는 데 사용됩니다.

### 사용자 정의 번역 추가

`ko-KR/Nodes/` 디렉터리에 JSON 파일을 생성하면 됩니다:

```json
{
  "YourNodeClassName": {
    "title": "노드 표시 이름",
    "inputs": {
      "input_name": "입력 이름 번역"
    },
    "outputs": {
      "output_name": "출력 이름 번역"
    },
    "widgets": {
      "widget_name": "위젯 이름 번역"
    },
    "ui": {
      "English text in panel": "패널 내 번역"
    }
  }
}
```

> **작성 팁**
>
> - `widgets`의 키는 위젯의 **실제 이름**(소스 파라미터 이름, 예 `target_language`)을 사용해야 합니다. 화면에 표시되는 display_name(예 `Target Language`)이 아닙니다. V3 API(io.Schema) 플러그인의 경우 실제 이름과 display_name 키를 모두 작성하면 호환성이 가장 좋습니다
> - `ui` 필드는 노드 내부 사용자 정의 패널(`addDOMWidget`로 생성)의 영어 텍스트를 번역하는 것으로, 키는 화면 표시 영어 원문, 값은 번역문입니다
> - '항등 번역'(키와 값이 동일한 항목, 예 `"cfg": "cfg"`)은 추가하지 마세요. 번역 의미가 없습니다
> - 키 철자를 확인하세요. 소스와 불일치하면(예 `perturb_atttn`에 t를 오타) 해당 위젯은 번역되지 않습니다

`ko-KR/Menus/` 디렉터리에 JSON 파일을 생성하면 메뉴 번역을 추가할 수 있습니다:

```json
{
  "English Menu Text": "메뉴 텍스트 번역",
  "Another Item": "다른 항목"
}
```

사전 파일의 최상위는 JSON 객체여야 합니다. 유효한 번역이 없으면 원문이 표시됩니다. 문제가 있는 파일은 건너뛰고 로그에 기록합니다. 사전을 파일 이름순으로 읽으며, 같은 키가 있으면 뒤에 있는 파일의 번역을 사용합니다. 노드가 속한 플러그인을 식별할 수 있으면 해당 사전을 우선 사용하고 부족한 필드는 다른 항목으로 채웁니다.

> 사전을 추가하거나 수정하거나 삭제한 뒤 브라우저 페이지를 새로고침하세요. 플러그인을 업데이트한 경우 ComfyUI를 먼저 재시작한 다음 페이지를 새로고침하세요.

### 청사진과 하위 그래프 번역

왼쪽의 ‘노드’ → ‘Comfy Blueprints’에서 청사진을 캔버스로 끌어오거나, 하위 그래프가 포함된 공식 템플릿이나 직접 만든 워크플로를 엽니다. 기존 캔버스와 새 노드 화면에서 노출된 포트, 위젯 레이블, 텍스트 입력란의 자리 표시자를 현재 언어로 번역합니다. 중첩된 하위 그래프에서 노출한 요소도 포함됩니다.

- 공식 청사진과 식별 가능한 공식 템플릿 하위 그래프의 제목은 현재 언어의 `Menus/`에서 찾습니다. 사용자가 만든 하위 그래프는 사용자가 붙인 제목을 유지합니다. 중국어 간체 제목과 공통 용어는 [ComfyUI-子图.json](zh-CN/Menus/ComfyUI-子图.json)에 있습니다.
- 노출 요소와 직접 대응하는 내부 노드의 번역을 우선 사용합니다. 해당 번역이 없으면 `Menus/`에서 표시 이름 전체를 찾습니다. 대소문자, 공백, 밑줄, 하이픈 차이를 허용하며 하나의 항목을 여러 하위 그래프에서 재사용할 수 있습니다.
- 입력과 출력의 번역을 구분하려면 `input.` 또는 `output.` 접두사를 사용합니다. 예를 들어 `output.depth_colored`는 같은 이름의 출력에 적용됩니다. 워크플로는 원래 제목, 포트 이름과 매개변수 값을 저장합니다.

### 핵심 기술

| 기술 | 설명 |
|------|------|
| **기본 우클릭 메뉴** | ComfyUI가 메뉴를 만든 후 레이블을 번역합니다. 메뉴 항목, 콜백 및 드롭다운 값은 원래 데이터를 사용합니다. |
| **이중 버튼 구조** | 구버전 `.comfy-menu`와 신버전 `.comfyui-menu` 두 UI 동시 호환 |
| **MutationObserver 감시** | 화면 변경을 감시하며 한 번에 들어온 메뉴 변경을 함께 검사합니다. |
| **translatedValueSet** | Set 구조로 O(1) 번역 여부 판단, 중복 처리 방지 |
| **리프 노드 보호** | `innerText`를 자식이 없는 노드에만 대입하여 Vue 이벤트 바인딩 보호 |
| **번역 캐시** | 백그라운드에서 번역을 구성하고 압축합니다. 사전과 비활성화 항목이 같으면 결과를 재사용합니다. |
| **하위 그래프 매칭 캐시** | 동일한 하위 그래프의 매칭 결과를 재사용하며 그래프 이름이나 노출 포트 식별자가 바뀌면 다시 매칭합니다. |
| **Gzip 압축 전송** | 브라우저가 Gzip을 허용하면 압축 데이터를 전송합니다. |

> 완전한 기술 세부 사항은 [TECHNICAL_DOCUMENTATION.md](TECHNICAL_DOCUMENTATION.md) 참조

## 주의 사항

### 호환성

- **번역 플러그인 충돌** — 본 플러그인은 다른 번역 플러그인(예 AIGODLIKE-ComfyUI-Translation)과 충돌하므로 사용 전 다른 플러그인을 제거하세요
- **알려진 충돌 플러그인** — `ComfyUI Browser`는 호환성 문제가 있을 수 있습니다
- **브라우저 지원** — Chrome, Edge, 360 브라우저 권장. 기타 브라우저는 충분히 테스트되지 않았습니다

### 번역이 아직 갱신되지 않을 때

- **페이지를 새로고침해도 이전 번역이 표시됩니다.** 일부 동기화 도구는 파일 크기, 수정 시간과 디렉터리 항목을 유지하면서 사전을 덮어씁니다. 이 경우 캐시가 계속 사용될 수 있습니다. ComfyUI를 재시작하면 사전을 다시 읽습니다.
- **팝업 갱신 후에도 텍스트가 영어로 표시됩니다.** 일부 팝업은 열린 직후 상태 텍스트를 변경합니다. 새 텍스트는 잠시 영어로 남을 수 있습니다.
- **하위 그래프의 연결을 바꾼 후에도 포트에 이전 번역이 표시됩니다.** 하위 그래프 안의 새 연결은 즉시 적용됩니다. 워크플로를 저장하고 다시 열면 노출된 포트에 맞는 번역을 다시 찾습니다.

### 환경 요구사항

| 구성 요소 | 요구사항 |
|------|------|
| ComfyUI | 최신 버전(구/신 버전 UI 호환) |
| Python | 3.8+ |
| 브라우저 | Chrome / Edge (권장) |

- 플러그인 내 '번역 언어' 설정 항목 제거. 번역 언어가 ComfyUI 공식 언어 설정(`Comfy.Locale`)을 자동 추적
- 공식 언어 전환 후 페이지가 자동 새로고침되며 번역과 플러그인 UI 문구가 동시에 반영. 수동 재시작 불필요

**설정 인터페이스 다국어 및 레이아웃 통일**

- 토글 텍스트와 설정 UI 문구가 15개 언어 커버(번체 중국어 및 아랍어·페르시아어·히브리어 RTL 언어 포함). 알 수 없는 언어는 영어로 폴백
- 모든 언어에서 설정 패널 배열 순서 통일: 토글 스타일 → 드롭다운 옵션 → 플러그인 번역 관리. 섹션 헤더도 언어별 번역
- '플러그인 번역 관리자' 패널은 사전으로 이중 번역되지 않아 항상 현재 인터페이스 언어와 일치
- 토글 켬 상태 문구에서 `(언어 코드)` 접미사를 제거하고 문구만 표시

### 2026-09-12

### 2026-07-27

**수정: V3 API 노드 위젯 번역 실패**

- V3 API(io.Schema)로 작성된 플러그인(예 ComfyUI-qwenmultiangle)에서 위젯이 번역되지 않던 문제 수정
- **원인**: V3 노드는 위젯에 영어 `display_name`을 선언하는 경우가 많아(name은 `horizontal_angle`, label은 `Horizontal Angle`), 기존 판정에서는 'label ≠ name'을 모두 기본 번역으로 간주해 건너뛰었습니다
- **대책**: `isAlreadyTranslated`에 정규화 비교를 추가. label이 name의 장식적 표현(대소문자/공백/언더스코어/하이픈 차이)에 불과하면 번역됨으로 간주하지 않음

**수정: 항등 번역이 번역됨 판정 집합을 오염**

- 특정 위젯(예 `cfg`)이 모든 노드에서 번역되지 않던 문제 수정
- **원인**: 일부 번역 파일에 '항등 번역'(`"cfg": "cfg"`)이 있어 그 값이 `translatedValueSet`에 들어간 뒤 영어 원명이 '이미 번역됨'으로 오인되어 해당 이름의 번역이 전역 차단되었습니다
- **대책**: 판정 집합 구축 시 키와 값이 동일한 항목 건너뛰기

**번역 파일 수정**

- ComfyUI-LTXVideo의 키 철자 오류 수정(`perturb_atttn`→`perturb_attn`, `cross_atttn`→`cross_attn`, `quantize_fnn`→`quantize_ffn`)
- ComfyUI-qwenmultiangle에 누락된 실제 위젯 이름 키(`target_language`, `prompt`) 보완

### 2026-04-08

**수정: 우클릭 메뉴 기능 상실**

- 번역 켬 상태에서 출력 포트 우클릭 메뉴의 '연결 끊기', '포트 이름 바꾸기' 등이 반응하지 않던 심각한 버그 수정
- **원인**: LiteGraph은 기층에서 `value.content` 영어 텍스트 매칭으로 콜백 액션을 분배하며, 번역 후 매칭 실패
- **대책**: 콜백 래핑(Callback Wrapping) 구현. 콜백 실행 순간에만 영어로 복원하고 실행 후 번역으로 되돌려, 번역 표시와 기능 정확성을 모두 확보
- `value.callback`(개별)과 `options.callback`(공유) 두 모드 모두 래핑
- `_originalContent` 다중 번역 덮어쓰기 보호 추가. 캔버스 메뉴가 번역 파이프라인을 두 번 통과해도 원값을 잃지 않음

**수정: DOM 번역이 이벤트 바인딩을 손상**

- `replaceText`의 `innerText` 대입이 자식 요소와 Vue/PrimeVue 리스너를 파괴하던 문제 수정
- **대책**: 리프 노드 검사 `target.children.length === 0` 추가하여 자식이 없는 노드에만 `innerText` 대입
