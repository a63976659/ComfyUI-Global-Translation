## הצגת התוסף

ComfyUI-Global-Translation הוא תוסף לתרגום רב־לשוני של הממשק. הוא משתמש בשפה שנבחרה ב־ComfyUI (הגדרות ← כללי ← `Comfy.Locale`) ומוסיף תרגומים לצמתים, לתפריטים, ללוח ההגדרות, למנהל ולממשקים של צמתי צד שלישי. הוא מתרגם גם טקסט בממשק שצמתי צד שלישי מעדכנים באופן דינמי. היקף התרגום תלוי במילון של כל שפה.

### למה לבחור בתוסף הזה?

| תכונה | תוסף זה | תוספי תרגום אחרים |
|------|--------|-------------|
| תואם לתרגום רשמי | ✅ מוסיף תרגומים בשפה שנבחרה ב־ComfyUI | ❌ עלול להתנגש |
| פונקציות תפריט לחיצה ימנית | ✅ ממשיכות לעבוד גם אחרי התרגום | ❌ חלק מהפונקציות נשברות |
| תואם לממשק ישן וחדש | ✅ ארכיטקטורת כפתור כפול | ❌ תומך בגרסה אחת בלבד |
| הפעלה וכיבוי של התרגום | ✅ שינוי המצב טוען את הדף מחדש | — |
| הגנה על כותרות מותאמות | ✅ אינו דורס שינויי משתמש | ❌ עלולים להידרס |

## תכונות ליבה

### 🎯 מערכת תרגום חכמה

- **זיהוי חכם** — מזהה אוטומטית טקסט שכבר מתורגם, ומונע תרגום חוזר ורקורסיה אינסופית
- **תאימות מובנית** — מתיישב להפליא עם התרגום הרשמי של ComfyUI ללא הפרעות הדדיות
- **מודעות להקשר** — מיישמת את האסטרטגיה המתאימה ביותר לפי סוג הרכיב (צמתים, תפריטים, ווידג'טים וכו')
- **מיזוג נתוני תרגום** — תרגומי צמתים בעלי שם זהה מתמזגים לפי שדות. כאשר אפשר לזהות את התוסף שהצומת שייך אליו, המילון שלו מקבל עדיפות
- **תרגום פאנלים מותאמים** — אפשר לתרגם כפתורים, תוויות בקרים, טקסט מציין מקום וחלונות קופצים בפאנלים מותאמים של צמתים
- **תרגום תפריט לחיצה ימנית** — התפריט מציג תוויות מתורגמות. פעולות כמו ניתוק חיבור ושינוי שם משתמשות בפריטי התפריט ובערכים המקוריים

### 🎨 ממשק משתמש יפה

- **פקד גלולה מפוצל** — מתג מעוגל בצורת גלולה עם מחוון כחול הגולש בחלקלקות בין פלגי "פועל/כבוי", מראה מודרני
- **אפקט קשת בענן** — במצב פעיל מציג אנימציה מדורגת זורמת של קשת בענן

- **מצב מובנה דיסקרטי** — לבחירה, ערכת צבעים רגועה התואמת את ערכת הנושא המובנית של ComfyUI
- **משוב בזמן אמת** — טקסט הכפתור וצבעו משקפים מיד את מצב התרגום הנוכחי

### 🔧 ניהול תרגום גמיש

- **החלפה בזמן אמת** — הפעלה/כיבוי תרגום ללא הפעלה מחדש
- **מצב מתמשך** — ההגדרות נשמרות אוטומטית ושרודות הפעלות מחדש
- **שילוב בלוח ההגדרות** — הגדרת סגנון המתג ותרגום אפשרויות התפריט הנפתח בהגדרות ComfyUI (השפה עוקבת אחר ההגדרה הרשמית של ComfyUI)
- **מתג תרגום לכל תוסף** — אפשר להפעיל או להשבית תרגומי צמתים לפי קובץ התרגום של התוסף
- **רענון המילון** — לאחר הוספה או עריכה של קובצי תרגום, רעננו את הדף כדי לטעון את התרגומים

## התקנה

### שיטה 1: העתקה באמצעות Git (מומלצת)

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/a63976659/ComfyUI-Global-Translation.git
```

הפעילו מחדש את ComfyUI לאחר ההתקנה.

#### שיטה 1 — מדריך מפורט למתחילים:

1. פתחו את תיקיית התוספים `ComfyUI\custom_nodes`
2. ב־Win11, לחיצה ימנית על אזור ריק ובחירה "פתח במסוף". ב־Win10, הקלידו `cmd` בשורת הכתובת ולחצו Enter.
3. לחצו על **Code** בפינה הימנית העליונה של עמוד זה והעתיקו את הכתובת (אפשר גם להעתיק את ה־URL)
4. במסוף הקלידו `git clone `, הדביקו את הכתובת ולחצו Enter. דוגמה: `git clone https://github.com/a63976659/ComfyUI-Global-Translation.git`
5. ההתקנה הושלמה, הפעילו מחדש את ComfyUI. (אם ההתקנה נכשלת, הפעילו פרוקסי/VPN ונסו שוב.)



### שיטה 2: ComfyUI Manager

1. פתחו את ComfyUI Manager
2. שנו את מקור הנתונים ל: ערוץ (מרחוק)
3. לחצו על מנהל הצמתים
4. חפשו אחר **猪的飞行梦**
5. לחצו על התקן והפעילו מחדש את ComfyUI

### שיטה 3: הורדה ידנית (לא מומלצת, ללא עדכונים)

1. בדף GitHub לחצו על **Code ← Download ZIP**
2. חלצו את הקובץ ל־`ComfyUI/custom_nodes/ComfyUI-Global-Translation`
3. הפעילו מחדש את ComfyUI

## שימוש

### מתג התרגום

לחצו על מתג התרגום בסרגל הכלים כדי להחליף מצב. במקלדת, לחצו על `Tab` כדי להתמקד בכפתור ואז על `Enter` או על מקש הרווח. לאחר שמירה מוצלחת, הדף יתרענן אוטומטית.

- **התרגום מופעל** — הכפתור מציג ״תרגום מופעל״ וטקסט הממשק מתורגם לשפה שנבחרה ב־ComfyUI.
- **התרגום מושבת** — הכפתור מציג ״תרגום כבוי״ ושוב מופיע הטקסט המקורי של ComfyUI ושל צמתים של צד שלישי.

### שפת התרגום

שפת התרגום אינה מוגדרת עוד בתוך התוסף; היא **עוקבת אוטומטית אחר הגדרת השפה הרשמית של ComfyUI** (הגדרות ← כללי ← שפה / `Comfy.Locale`):

- התוסף תואם לכל 14 השפות שנתמכות רשמית ב־ComfyUI: סינית מפושטת, סינית מסורתית, אנגלית, יפנית, קוריאנית, רוסית, צרפתית, ספרדית, איטלקית, פורטוגזית (ברזיל), טורקית, ערבית, פרסית, עברית; שפות שאינן מכוסות חוזרות לאנגלית
- התוסף כולל מילון לגרמנית (`de-DE`). עדיין אי אפשר לבחור גרמנית בהגדרות השפה הרשמיות של ComfyUI.
- לאחר החלפת השפה הרשמית בהגדרות ComfyUI, הדף מתרענן אוטומטית; התרגום וטקסטי התוסף מוחלים יחד, ללא צורך בהפעלה מחדש ידנית

### לוח ההגדרות

בהגדרות ComfyUI ← «🌐 הגדרות תרגום» ישנן שתי אפשרויות. טקסטי הממשק מתורגמים לשפה הנוכחית עם סדר מקטעים עקבי בכל השפות:

| אפשרות | תיאור | בחירות |
|-------|------|------|
| 🎨 סגנון המתג | בחרו את המראה; משתנה מיד ללא רענון | pill (גלולה מפוצלת) / gradient (קשת בענן) / plain (מובנה דיסקרטי) |
| 📋 אפשרויות נפתחות | האם לתרגם גם את טקסט האפשרויות בתפריטים נפתחים מסוג COMBO | פועל / כבוי (מתרענן אוטומטית בשינוי) |

לוח **ניהול תרגום תוספים** שמתחת להגדרות מציג את קובצי תרגום הצמתים הזמינים. בטלו את הסימון של קובץ כדי להשבית את תרגומי הצמתים שבו. לאחר טעינת הרשימה, כאשר יש פריטים לבחירה, לחצו על ״שמור וטען מחדש״. הבחירות להשבתת תרגומים בשפות אחרות נשמרות. אם השמירה נכשלת, הלוח יציג הודעה ויאפשר לנסות שוב.

### מבנה קבצי התרגום

```
he-IL/
├── Nodes/          # תרגומי צמתים (כותרת, כניסות, יציאות, ווידג'טים, פאנלים מותאמים)
│   └── internal.json
├── Categories/     # תרגומי קטגוריות צמתים
│   ├── Internal.json
│   └── Other.json
└── Menus/          # תרגומי תפריטים וממשק
    ├── Comfy设置菜单及管理器菜单.json
    ├── Comfy条件选项.json
    ├── ComfyUI-子图.json
    ├── Comfy模版汉化-zdfxm.json
    └── ...
```

> שאר תיקיות השפה (`zh-CN/`, `zh-TW/`, `en-US/`, `ja-JP/`, `ko-KR/`, `ru-RU/`, `fr-FR/`, `es-ES/`, `it-IT/`, `pt-BR/`, `ar-SA/`, `tr-TR/`, `fa-IR/`) חולקות את אותו המבנה ונטענות לפי השפה הנוכחית; `en-US/` משמשת לשחזור צמתים של תוספים לא־סיניים חזרה לאנגלית. גם תיקיות שפה המכילות רק את `Menus/` או `Categories/` מזוהות.

```json
    "title": "שם התצוגה של הצומת שלכם",
    "inputs": {
      "input_name": "תרגום שם הכניסה"
    },
    "outputs": {
      "output_name": "תרגום שם היציאה"
    },
    "widgets": {
      "widget_name": "תרגום שם הווידג'ט"
    },
    "ui": {
      "English text in panel": "תרגום טקסט הפאנל"
    }
  }
}
```

> **טיפי כתיבה**
>
> - המפתחות ב־`widgets` חייבים להשתמש ב**שם האמיתי** של הווידג'ט (שם הפרמטר במקור, למשל `target_language`), לא ב־display_name המוצג על המסך (למשל `Target Language`). עבור תוספים הכתובים ב־V3 API (io.Schema), רשמו הן את השם האמיתי והן את ה־display_name כמפתחות לקבלת התאימות הטובה ביותר
> - השדה `ui` מתרגם טקסטים באנגלית בתוך פאנלים מותאמים (שנוצרו באמצעות `addDOMWidget`); המפתח הוא הטקסט האנגלי המוצג על המסך, הערך הוא התרגום
> - אל תוסיפו "תרגומי זהות" (ערך השווה למפתח שלו, למשל `"cfg": "cfg"`) — אין להם שום משמעות
> - בדקו פעמיים את הכתיב של המפתחות; מפתח השונה מזה שבמקור (למשל `t` מיותר ב־`perturb_atttn`) ייכשל בשקט ולא יתורגם

צרו קובץ JSON תחת `he-IL/Menus/` כדי להוסיף תרגומי תפריטים:

```json
{
  "English Menu Text": "תרגום טקסט התפריט",
  "Another Item": "פריט אחר"
}
```

> לאחר הוספת מילון, עריכתו או מחיקתו, רעננו את דף הדפדפן כדי לטעון את התרגומים העדכניים. לאחר עדכון התוסף, הפעילו מחדש את ComfyUI ואז רעננו את הדף.

### תרגום תבניות ותתי־גרפים

גררו תבנית לקנבס מתוך ״צמתים ← תבניות Comfy״ בסרגל הצד או פתחו תבנית רשמית או זרימת עבודה משלכם שמכילה תת־גרף. בקנבס הקלאסי ובממשק הצמתים החדש, חיבורים חשופים, תוויות בקרים וטקסט מציין מקום בתיבות טקסט מתורגמים לשפה הנוכחית, לרבות רכיבים שנחשפו מתוך תתי־גרפים מקוננים.

- כותרות תבניות רשמיות ותתי־גרפים שניתן לשייך לתבניות רשמיות מתורגמות באמצעות `Menus/` של השפה הנוכחית. תתי־גרפים שיצרו המשתמשים שומרים על הכותרות שנתנו להם. כותרות ומונחים משותפים בסינית מפושטת נמצאים בקובץ [ComfyUI-子图.json](zh-CN/Menus/ComfyUI-子图.json).
- ברכיב חשוף, תרגום הצומת הפנימי המקביל מקבל עדיפות. בהיעדר תרגום מתאים, מחפשים את שם התצוגה המלא ב־`Menus/` של השפה הנוכחית. ההתאמה מביאה בחשבון הבדלים באותיות גדולות וקטנות, ברווחים, בקווים תחתונים ובמקפים. אפשר להשתמש באותו ערך מילון בכמה תתי־גרפים.
- כשנדרש תרגום שונה לקלט ולפלט, הוסיפו לערך המשותף את הקידומת `input.` או `output.`. לדוגמה, `output.depth_colored` יכול להציג את הפלט המתאים בתור ״מפת עומק בצבע״. זרימת העבודה שומרת את הכותרות, שמות החיבורים וערכי הפרמטרים המקוריים.

## הערות

### תאימות

- **התנגשויות עם תוספי תרגום** — תוסף זה מתנגש עם תוספי תרגום אחרים (למשל AIGODLIKE-ComfyUI-Translation); הסירו אותם לפני השימוש
- **תוסף ידוע בהתנגשות** — `ComfyUI Browser` עלול להיות בעל בעיות תאימות
- **תמיכת דפדפנים** — מומלצים Chrome, Edge ו־360 Browser; האחרים לא נבדקו במלואם

### כשהתרגומים עדיין אינם מעודכנים

- **עדיין מופיע תרגום ישן לאחר רענון הדף.** כלי סנכרון מסוימים מחליפים מילונים תוך שמירה על גודל הקובץ, זמן השינוי ורישומי התיקייה. התוסף עשוי להמשיך להשתמש במטמון הישן. הפעילו מחדש את ComfyUI כדי לקרוא מחדש את המילונים.
- **הטקסט נשאר באנגלית לאחר עדכון חלון קופץ.** חלונות מסוימים מעדכנים את טקסט המצב ישירות אחרי פתיחתם. הטקסט החדש עשוי להישאר זמנית באנגלית.
- **חיבור חשוף עדיין מציג את התרגום הישן לאחר חיבור מחדש.** כשמחברים את החיבור לצומת אחר בתוך תת־גרף, החיבור החדש נכנס לתוקף מיד. שמרו ופתחו מחדש את זרימת העבודה כדי להתאים מחדש את תרגום החיבור החשוף.

- תווית מצב הפועל של המתג מוותרת על הסיומת `(קוד שפה)` ושומרת רק על הטקסט

### 2026-07-27

**תיקון: כשל בתרגום ווידג'טים של צמתים ב־V3 API**

- תוקן מצב שבו ווידג'טים לא תורגמו בתוספים הכתובים ב־V3 API (io.Schema), למשל ComfyUI-qwenmultiangle
- **הסיבה השורשית**: צמתים V3 מכריזים לעיתים קרובות על `display_name` באנגלית עבור ווידג'ט (השם `horizontal_angle`, התווית `Horizontal Angle`); הבדיקה הישנה "כבר תורגם" טיפלה בכל "תווית ≠ שם" כתרגום מובנה ודילגה עליו
- **התיקון**: `isAlreadyTranslated` הוסיפה השוואה מנורמלת — תווית שהיא רק שם מעוצב (הבדלי רישיות/רווח/קו תחתון/מקף) אינה נחשבת מתורגמת

**תיקון: תרגומי זהות שהזהימו את קבוצת "כבר תורגם"**

- תוקן מצב שבו ווידג'טים מסוימים (למשל `cfg`) לעולם לא תורגמו באף צומת
- **הסיבה השורשית**: בחלק מהקבצים היו רשומות זהות (למשל `"cfg": "cfg"`); ברגע שערכן נכנס ל־`translatedValueSet`, השם האנגלי קרא בטעות כ"כבר תורגם" ונחסם גלובלית
- **תיקון**: דילג על רשומות שערכן שווה למפתח שלהן בעת בניית הקבוצה

**תיקוני קבצי תרגום**

- תוקנו שגיאות כתיב של מפתחות ב־ComfyUI-LTXVideo (`perturb_atttn`→`perturb_attn`, `cross_atttn`→`cross_attn`, `quantize_fnn`→`quantize_ffn`)
- נוספו מפתחות חסרים של שמות ווידג'טים אמיתיים ל־ComfyUI-qwenmultiangle (`target_language`, `prompt`)

### 2026-04-08

**תיקון: שבירת פונקציות תפריט הלחיצה הימנית**

- תוקן באג חמור שבו, כאשר התרגום פעיל, פעולות כמו "נתק" ו"שינוי שם יציאה" בתפריט הלחיצה הימנית של יציאת צומת חדלו להגיב
- **הסיבה השורשית**: LiteGraph מפעיל קריאות חוזרות באמצעות התאמת `value.content` האנגלי; לאחר התרגום ההתאמה נכשלה
- **התיקון**: יישום עטיפת קריאות חוזרות — האנגלית משוחזרת באופן זמני ברגע הפעלת הקריאה החוזרת, ואז הסינית משוחזרת, ובכך נשמרים הן התצוגה המתורגמת והן ההתנהגות הנכונה
- עוטף הן את מצב `value.callback` (יחיד) והן את `options.callback` (משותף)
- נוספה הגנת דריסת `_originalContent` ריבוי־תרגומים כדי שתפריט הלוח לא יאבד את ערכו המקורי לאחר מעבר פעמיים דרך הצנרת

**תיקון: תרגום DOM ששבר את קישורי האירועים**

- תוקן מצב שבו השמה של `innerText` ב־`replaceText` הרסה רכיבי ילד ומאזינים של Vue/PrimeVue
- **התיקון**: נוסף בדיקת צומת עלה `target.children.length === 0`, המשייכת `innerText` רק לצמתים ללא ילדים
